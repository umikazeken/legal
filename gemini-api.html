Gemini APIについて

このページはGemini APIを利用する各アプリ共通の説明ページです。

Gemini APIキーを取得する

APIキーとは、アプリがGoogle Geminiに接続するための「合言葉」のようなものです。以下の手順で無料で発行できます。

  1. iPhoneまたはパソコンのブラウザでGoogle AI Studio（aistudio.google.com/apikey）を開きます。
  2. お持ちのGoogleアカウント（Gmailなど）でログインします。初回は利用規約への同意を求められることがあります。
  3. 画面に表示される「APIキーを作成」（英語表示の場合は「Create API key」）ボタンをタップします。すでにGoogle Cloudプロジェクトをお持ちでない場合は、専用のプロジェクトが自動的に作成されます（難しい設定は不要です）。
  4. 「AIza」から始まる長い文字列が表示されます。これがAPIキーです。キーの右にあるコピーアイコンをタップして、文字列をコピーしておきます。
  5. APIキーはパスワードと同じくらい大切な情報です。他人に見せたり、SNSなどに書き込んだりしないよう注意してください。

アプリに登録する（例: WiseWatchの場合）

取得したAPIキーは、お使いのアプリの設定画面に貼り付けます。以下はWiseWatchでの手順の例です（他のアプリでも概ね同じ流れです）。

  1. WiseWatchアプリを開き、下部タブの「設定」をタップします。
  2. 一番上にある「Gemini APIキー」の入力欄をタップします。
  3. 入力欄を長押しし、表示されるメニューから「ペースト」（貼り付け）を選び、先ほどコピーしたキーを貼り付けます。
  4. 画面の別の場所をタップして、入力欄からフォーカスを外します。これで自動的に保存されます。
  5. 少し待つと「有効なAPIキーです」という緑色の表示が出れば設定完了です。「APIキーが無効です」と赤字で表示された場合は、コピー時に余計な空白や改行が混ざっていないか確認し、貼り付け直してください。

無料枠の利用制限について知っておく

Gemini APIの無料枠には「1分あたりのリクエスト数」「1日あたりのリクエスト数」などの制限があり、モデルや時期によってGoogle側で変更されることがあります。最新の値はGoogle公式のレート制限ページでご確認ください。上限に達すると、アプリ側にエラーメッセージが表示されます（表示内容はアプリによって異なります）。

ご自身でGoogle Cloudの有料プラン（従量課金）を契約していない限り、無料枠の上限に達しても自動的に課金されることはなく、単に一時的に利用できなくなるだけです。一方、すでに有料プランを契約済みの場合は、無料枠を使い切ると自動的に有料枠へ切り替わって利用が続けられる代わりに、その分の料金が発生する可能性がありますのでご注意ください。

About the Gemini API

This page is a shared reference used by multiple apps that rely on the Gemini API.

Get a Gemini API key

An API key is like a password that lets an app connect to Google Gemini. Here's how to generate one for free:

  1. Open a web browser (on your phone or a computer) and go to Google AI Studio (aistudio.google.com/apikey).
  2. Sign in with your Google account (e.g., a Gmail address). The first time, you may be asked to accept the terms of service.
  3. Tap the "Create API key" button. If you don't already have a Google Cloud project, one is created for you automatically — no advanced setup needed.
  4. A long string starting with "AIza" appears — this is your API key. Tap the copy icon next to it to copy it.
  5. Treat your API key like a password: never share it with anyone or post it publicly (e.g., on social media).

Enter it into your app (example: WiseWatch)

Paste the key you copied into your app's settings screen. Below is an example using WiseWatch (most apps follow roughly the same flow):

  1. Open WiseWatch and tap "Settings" in the bottom tab bar.
  2. Tap the "Gemini API Key" field at the top.
  3. Press and hold in the field, then choose "Paste" from the menu that appears to insert the key you copied.
  4. Tap elsewhere on the screen to move focus away from the field — this saves it automatically.
  5. After a moment, a green "Valid API key" message confirms it worked. If you see a red "Invalid API key" message, check for extra spaces or line breaks from copying, and paste it again.

Know the free-tier usage limits

The Gemini API free tier has limits such as requests-per-minute and requests-per-day, which vary by model and can change over time on Google's side. Check the current values on Google's official rate limits page. When you hit a limit, the app will show an error message (the exact wording varies by app).

Unless you have personally signed up for a paid (pay-as-you-go) plan on Google Cloud, hitting the free tier limit never results in a charge — it simply becomes temporarily unavailable. If you have already signed up for a paid plan, requests automatically switch to the paid tier once the free tier is used up so you can keep going, but note that this may incur charges.
