WiseWatch ではじめに

本アプリについて

WiseWatchは、Apple Watch単体でGoogle Geminiと音声・テキストで会話できるAIアシスタントアプリです。

Gemini API の無料枠を使用しているため「1分あたりのリクエスト数」などの制限はありますが、月額課金なしでご利用いただけます。

はじめに（初期設定ガイド）

  • 本アプリを使用するためにはGemini APIキーの設定が必要です。詳細は「Gemini APIキーを取得する」を参照してください。
  • Watchからの入力は音声またはキーボード（対応機種のみ）が使用できます。詳細はApple公式: Apple Watchでテキストを入力するを参照してください。
  • 本アプリをWatchの文字盤に登録すると、ワンタップで起動できます。詳細はApple公式: Apple Watchの文字盤にコンプリケーションを追加するを参照してください。

本アプリの使い方

  • マイクボタンをタップして話しかけると、Geminiの回答が画面に表示されます。
  • スピーカーボタンをタップすると、回答の読み上げをON/OFFできます。

Gemini API の無料枠を使用しているため「1分あたりのリクエスト数」などの制限はありますが、月額課金なしでご利用いただけます。

その他のご質問はサポートページをご覧ください。

Getting Started with WiseWatch

About This App

WiseWatch is an AI assistant app that lets you talk with Google Gemini by voice or text, directly from your Apple Watch.

Because it uses the Gemini API's free tier, there are limits such as requests-per-minute, but there's no monthly subscription fee to use it.

Getting Started

  • You'll need to set up a Gemini API key to use this app. See "Get a Gemini API key" for details.
  • You can input on Apple Watch by voice or with the on-screen keyboard (supported models only). See Apple: Enter text on Apple Watch for details.
  • Add WiseWatch as a complication on your watch face to launch it with one tap. See Apple: Add complications to the watch face for details.

How to Use This App

  • Tap the microphone button and speak — Gemini's reply appears on screen.
  • Tap the speaker button to turn spoken replies on or off.

Because it uses the Gemini API's free tier, there are limits such as requests-per-minute, but there's no monthly subscription fee to use it.
