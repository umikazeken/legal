プライバシーポリシー

アプリ名：WiseWatch  |  最終更新：2026年9月13日

1. 収集する情報

WiseWatch は、アカウント登録や個人を特定できる情報の収集を行いません。

ユーザーが入力したGemini APIキー、選択したモデル、カスタム指示はお使いのiPhone内のKeychain/端末内にのみ保存され、当方や当方が管理するサーバーに送信されることはありません。

2. Apple Watch との同期

APIキー・使用するモデル・カスタム指示・現在地情報の利用設定は、Apple の WatchConnectivity フレームワークを使用してiPhoneとApple Watchの間で同期されます。このデータはお客様ご自身のデバイス間でのみやり取りされ、第三者に送信されることはありません。

3. Gemini APIへの送信

Apple Watch上での音声・テキストによる会話内容は、ユーザーご自身が設定したAPIキーを用いて、Google の Gemini API に直接送信され、応答の生成に利用されます。会話内容は当方のサーバーを経由せず、当方が保存・閲覧することもありません。

Gemini APIにおけるデータの取り扱いについては、Google のプライバシーポリシーをご確認ください。

4. 現在地情報

設定画面で「現在地情報を利用する」をONにした場合のみ、Apple WatchのGPSから取得した現在地（緯度・経度）が、ユーザーの発話とともにGemini APIへ送信されます。この機能はいつでも設定画面からOFFにでき、OFFの場合は位置情報の取得・送信は行われません。位置情報は当方のサーバーには送信・保存されません。

5. 音声の読み上げ・音声入力

応答の読み上げにはApple標準の音声合成（AVSpeechSynthesizer）を使用しており、端末内で処理され外部に送信されることはありません。音声入力（ディクテーション）はwatchOS標準のディクテーション機能を使用します。

6. 第三者への提供

当方は、上記のGemini APIへの送信を除き、いかなる情報も第三者に販売・提供・開示することはありません。

7. 分析・広告

本アプリは広告ネットワークおよびサードパーティの分析ツールを使用していません。

Privacy Policy

App: WiseWatch  |  Last updated: September 13, 2026

1. Information We Collect

WiseWatch does not require account registration and does not collect any personally identifiable information.

Your Gemini API key, selected model, and custom instructions are stored locally on your iPhone's Keychain/local storage only and are never sent to us or to any server we operate.

2. Apple Watch Sync

Your API key, selected model, custom instructions, and location feature setting are synced between your iPhone and Apple Watch using Apple's WatchConnectivity framework. This data is exchanged only between your own devices and is never sent to any third party.

3. Sending Data to the Gemini API

Conversations (voice or text) on Apple Watch are sent directly to Google's Gemini API using the API key you provide, in order to generate responses. This data does not pass through, or get stored or viewed by, any server operated by us.

Please refer to Google's own privacy policy for how the Gemini API handles data.

4. Location Information

Only when you turn on "Use current location" in Settings, your current location (latitude/longitude), obtained via Apple Watch's GPS, is sent to the Gemini API together with your message. You can turn this off at any time in Settings; when off, no location data is collected or sent. Location data is never sent to or stored on any server we operate.

5. Speech Output and Voice Input

Spoken responses use Apple's built-in speech synthesis (AVSpeechSynthesizer), which is processed entirely on-device and never transmitted externally. Voice input uses watchOS's built-in dictation feature.

6. Third-Party Sharing

Other than sending data to the Gemini API as described above, we do not sell, share, or disclose any information to third parties.

7. Analytics & Advertising

This app does not use any advertising networks or third-party analytics tools.
